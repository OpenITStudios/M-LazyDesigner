# Modelling

Owns geometry/modelling policy and profile-specific modelling knowledge.

```text
standard.md
profiles/README.md
profiles/<selected-profile>.md
knowledge-curation.md        (conditional: source/adoption criteria)
decision-cases.md           (conditional: eight G1 decision examples)
research-sources.md         (conditional: curated external research + rights)
geometry-intelligence-plan.md (conditional: modular implementation design)
```

`standard.md` owns the universal **Bedrock-native representation and anti-overcube policy**, including Adaptive Cuboid Budget, Marginal Geometry Value, Representation Ladder, segmented-curve rules, and the cohort merge/remove challenge. Profiles may specialize asset decisions but must not replace those universal rules with fixed Cube counts.

[Geometry Knowledge Curation](knowledge-curation.md) owns gap-first adoption and evidence requirements; the [G1 decision casebook](decision-cases.md) contains eight positive/negative source examples. The [curated research sources](research-sources.md) document provenance, licenses and relevance; the [implementation design](geometry-intelligence-plan.md) maps future Geometry improvements to existing Recipe/Runtime/Validation owners. None is a second modelling policy or asset preset.

AI load rule: load `standard.md` plus exactly one primary profile by default. Secondary profile guidance must be narrow and decision-specific. Load `knowledge-curation.md`, `research-sources.md` or `geometry-intelligence-plan.md` only for explicit research/development. Read just the relevant casebook section on an unresolved Geometry decision.
